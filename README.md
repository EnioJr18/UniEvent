# UniEvent

Plataforma web para gerenciamento de eventos universitários.

## Objetivo

O UniEvent centraliza a criação, publicação, inscrição, acompanhamento, controle de presença e emissão de certificados para eventos acadêmicos.

## Stack

- Backend: Python, Django, Django REST Framework
- Banco de dados: PostgreSQL
- Frontend: TypeScript, React, Tailwind CSS
- Gestão: GitHub Projects, Scrum + Kanban

## Fluxo de desenvolvimento

- `main`: versão estável
- `develop`: integração contínua das funcionalidades
- `feature/*`: novas funcionalidades
- `fix/*`: correções
- `docs/*`: documentação

As alterações relevantes deverão passar por Pull Request e revisão antes do merge.
